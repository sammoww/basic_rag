StepA

📄 Read Raw Documents (vector_store.py)

You add files (like data/sample.txt). Python reads the text content from the disk.

vector_store.py
↓ Chunks text into smaller paragraphs
StepB

✂️ Split into 500-Character Chunks

RecursiveCharacterTextSplitter chops long text into digestible pieces so each piece has a focused topic.

LangChain
↓ Sends raw text to Google Embedding API
StepC

☁️ Google Embedding Model (gemini-embedding-2)

Google translates each chunk's meaning into a list of 768 coordinate numbers (vectors) and sends them back.

Google Cloud API
↓ Saves coordinates to disk
StepD

💾 Saved Locally in FAISS (faiss_db/)

FAISS indexes these coordinate numbers in your project folder so they can be searched in milliseconds later.

Local Disk

There are only two places in this entire project where API calls leave your machine:

☁️ 1. Embedding API (Google)

  • Model: models/gemini-embedding-2
  • File: vector_store.py
  • What it does: Converts text words into mathematical coordinate lists (vectors).
  • Cost: Free tier (Google AI Studio).

☁️ 2. Chat Generation API (Google / Groq)

  • Primary Model: gemini-3.5-flash
  • Fallback Model: llama3-8b-8192 (Groq)
  • File: app.py
  • What it does: Reads your question + retrieved facts to formulate natural English answers.
  • Cost: Free tier.

🗄️ What is NOT an API? (100% Local on your machine)

  • FAISS Database: Runs on your local CPU and saves files to ./faiss_db. No data sent to Meta.
  • Streamlit UI: Runs locally on http://localhost:8501.
  • Text Splitting & Orchestration: LangChain executes right inside your Python environment.
